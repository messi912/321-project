About the Project

Polynesian Language Reconstruction

Overview

This project is a end to end pipeline, which takes in Polynesian Language data, and predicts missing words. We used a sequence to sequence machine learning model for the language prediction. The whole project is written in python, with the PyTorch Libary being utilized for the model and pandas being utilized for data cleaning.
